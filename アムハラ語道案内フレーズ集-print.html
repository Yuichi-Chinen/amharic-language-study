አቅጣጫ

アムハラ語 道案内フレーズ集

場所を尋ねる、道順を聞き取る、目印で位置を言う、タクシーやミニバスに乗る。道順の指示は話しかける相手(男性・女性・目上・複数)で形が変わるので、その形も並べた。

ለማን?道順の指示は相手で形が変わる

男性へ− 語尾なしታጠፍ · ሂድ
女性へ-ኢ -iታጠፊ · ሂጂ
目上の人へይ- … -ኡ yə- … -uይታጠፉ · ይሂዱ
複数の人へ-ኡ -uታጠፉ · ሂዱ

የት ነው?場所を尋ねる

日本語相手フィデル読み方備考
〜はどこですか… የት ነው?… イェト・ネウ?… yät näw?የት は「どこ」。例: ባንክ የት ነው?(バンク・イェト・ネウ?)= 銀行はどこですか。
トイレはどこですかመታጠቢያ ቤት የት ነው?メタテビヤ・ベト・イェト・ネウ?mätaṭäbiya bet yät näw?ሽንት ቤት(シント・ベト)とも言う。
遠いですかሩቅ ነው?ルク・ネウ?ruq näw?答えは ሩቅ ነው(遠い)/ ቅርብ ነው(クルブ・ネウ = 近い)。
何分かかりますかስንት ደቂቃ ይወስዳል?シント・デキカ・イウェスダル?sənt däqiqa yəwäsdal?ደቂቃ は「分」。答えの例: አምስት ደቂቃ(アムスト・デキカ)= 5分。
歩いて行けますかበእግር መሄድ ይቻላል?ベイグル・メヘド・イッチャラル?bä'əgər mähed yəččalal?በእግር は「足で・歩いて」。
地図で教えてください男性へካርታ ላይ አሳየኝカルタ・ライ・アサイェニュkarta lay asayäñ直訳は「地図の上で見せて」。スマートフォンの地図を見せながら。
女性へካርታ ላይ አሳዪኝカルタ・ライ・アサイニュkarta lay asayiñ
目上の人へካርታ ላይ ያሳዩኝカルタ・ライ・ヤサユニュkarta lay yasayuñ
複数の人へካርታ ላይ አሳዩኝカルタ・ライ・アサユニュkarta lay asayuñ
道に迷いましたጠፋሁテッファフṭäffahuጠፋ(なくなる・迷う)から。「私は迷った」。

አቅጣጫ道順の指示

日本語相手フィデル読み方備考
右に曲がって男性へወደ ቀኝ ታጠፍウェデ・ケニュ・タテフwädä qäñ taṭäfወደ は「〜へ」、ቀኝ は「右」。Wikivoyage では目上の人にも複数形の ታጠፉ を使っている。
女性へወደ ቀኝ ታጠፊウェデ・ケニュ・タテフィwädä qäñ taṭäfi
目上の人へወደ ቀኝ ይታጠፉウェデ・ケニュ・イタテフwädä qäñ yətaṭäfu
複数の人へወደ ቀኝ ታጠፉウェデ・ケニュ・タテフwädä qäñ taṭäfu
左に曲がって男性へወደ ግራ ታጠፍウェデ・グラ・タテフwädä gəra taṭäfግራ は「左」。
女性へወደ ግራ ታጠፊウェデ・グラ・タテフィwädä gəra taṭäfi
目上の人へወደ ግራ ይታጠፉウェデ・グラ・イタテフwädä gəra yətaṭäfu
複数の人へወደ ግራ ታጠፉウェデ・グラ・タテフwädä gəra taṭäfu
まっすぐ行って男性へቀጥታ ሂድケッティタ・ヒドqäṭṭəta hidቀጥታ は「まっすぐ」。ሂድ は「行け」。
女性へቀጥታ ሂጂケッティタ・ヒジqäṭṭəta hiǧi
目上の人へቀጥታ ይሂዱケッティタ・イヒドゥqäṭṭəta yəhidu
複数の人へቀጥታ ሂዱケッティタ・ヒドゥqäṭṭəta hidu
戻って男性へተመለስテメレスtämäläs行き過ぎたときに言われる。
女性へተመለሺテメレシtämäläši
目上の人へይመለሱイメッレスyəmmäläsu
複数の人へተመለሱテメレスtämäläsu
それからከዚያケッズィヤkäzziya道順をつなぐ。例: ቀጥታ ሂድ፣ ከዚያ ወደ ግራ ታጠፍ = まっすぐ行って、それから左に曲がって。

ቦታ位置の言い方

日本語相手フィデル読み方備考
〜の隣ですከ… አጠገብ ነውケ… アテゲブ・ネウkä… aṭägäb näw例: ከባንኩ አጠገብ ነው(ケバンク・アテゲブ・ネウ)= 銀行の隣です。語尾の -ኡ は「その」。
〜の向かいですከ… ፊት ለፊት ነውケ… フィト・レフィト・ネウkä… fit läfit näwፊት ለፊት は直訳で「顔と顔」。
〜の後ろですከ… ኋላ ነውケ… フワラ・ネウkä… hwala näw
右側ですበቀኝ በኩል ነውベケニュ・ベックル・ネウbäqäñ bäkkul näw左側は በግራ በኩል(ベグラ・ベックル)。
ここですእዚህ ነውイッズィフ・ネウəzzih näw
あそこですእዚያ ነውイッズィヤ・ネウəzziya näw

ታክሲ እና አውቶቢስタクシー・バスに乗る

日本語相手フィデル読み方備考
〜までいくらですかወደ … ስንት ነው?ウェデ … シント・ネウ?wädä … sənt näw?例: ወደ ቦሌ ስንት ነው?(ウェデ・ボレ・シント・ネウ?)= ボレまでいくら? タクシーは乗る前に値段を決める。
〜まで行ってください男性へወደ … ውሰደኝウェデ … ウセデニュwädä … wəsädäñ直訳は「〜へ私を連れて行って」。
女性へወደ … ውሰጂኝウェデ … ウセジニュwädä … wəsäǧiñ
目上の人へወደ … ይውሰዱኝウェデ … イウセドゥニュwädä … yəwsäduñ
複数の人へወደ … ውሰዱኝウェデ … ウセドゥニュwädä … wəsäduñ
このバスは〜へ行きますかይሄ አውቶቢስ ወደ … ይሄዳል?イヘ・アウトビス・ウェデ … イヘダル?yəhe awtobis wädä … yəhedal?ミニバスなら አውቶቢስ を ሚኒባስ(ミニバス)に。
ここで止めてください男性へእዚህ ቁምイッズィフ・クムəzzih qumቁም は「止まれ・立て」。
女性へእዚህ ቁሚイッズィフ・クミəzzih qumi
目上の人へእዚህ ይቁሙイッズィフ・イクムəzzih yəqumu
複数の人へእዚህ ቁሙイッズィフ・クムəzzih qumu
降ります!ወራጅ አለ!ウェッラジ・アッレ!wärraǧ allä!直訳は「降りる人がいます」。ミニバスで降りたいときの決まり文句。

ውይይት会話の例(A = 男性の旅行者、B = 道を教える人、C = タクシーの運転手)

Aይቅርታ፣ ቤተ ክርስቲያን የት ነው?イキルタ、ベテ・クリスティヤン・イェト・ネウ?すみません、教会はどこですか。
Bቀጥታ ሂድ፣ ከዚያ ወደ ግራ ታጠፍ።ケッティタ・ヒド、ケッズィヤ・ウェデ・グラ・タテフ。まっすぐ行って、それから左に曲がって。
Aሩቅ ነው?ルク・ネウ?遠いですか。
Bአይ፣ ቅርብ ነው። አምስት ደቂቃ።アイ、クルブ・ネウ。アムスト・デキカ。いいえ、近いです。5分です。
Bከባንኩ ፊት ለፊት ነው።ケバンク・フィト・レフィト・ネウ。銀行の向かいです。
Aአመሰግናለሁ!アメセギナレフ!ありがとう!
Aወደ ቦሌ ስንት ነው?ウェデ・ボレ・シント・ネウ?(タクシーで)ボレまでいくらですか。
Cሶስት መቶ ብር።ソスト・メト・ブル。300ブル。
Aበጣም ውድ ነው። ሁለት መቶ ይሆናል?ベタム・ウッド・ネウ。フレト・メト・イホナル?高すぎます。200でどうですか。
Cእሺ፣ ግባ።イッシ、ギバ。いいよ、乗って。
Aእዚህ ቁም። አመሰግናለሁ!イッズィフ・クム。アメセギナレフ!ここで止めてください。ありがとう!

使うときの注意

  • エチオピアでは住所より目印で道を説明するのが普通。「〜の隣」「〜の向かい」と、銀行・教会・広場(አደባባይ)などの目印を組み合わせて覚える。
  • 道順の指示は命令形なので、教えてくれる人は自分(旅行者)に合わせた形で言う。男性の旅行者には ታጠፍ、女性の旅行者には ታጠፊ が聞こえてくる。
  • タクシーにはメーターがないことが多い。乗る前に行き先と値段を決める(値段交渉は「数字と買い物フレーズ集」を参照)。
  • ミニバスは呼び込みの係が行き先を叫んでいる。乗る前に行き先を確かめ、降りるときは ወራጅ አለ と声をかける。
  • ボレ(ቦሌ)はアディスアベバの空港がある地区。地名は ወደ … の … に入れればよい。
  • カタカナは目安。放出音(ጠ ጣ ቅ など)は日本語にない音なので、音源で確認すること。
