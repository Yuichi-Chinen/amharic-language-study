## 作業履歴

1. **フィデル表 作成** — アムハラ語の音節文字(フィデル)全34子音系列×7母音段=231文字を、ローマ字表記・カタカナ読み付きで一覧化。唇音化系列(qʷ/ḫʷ/kʷ/gʷ)、放出音、歴史的に統合された文字(ሀ/ሐ/ኀ/ኸ→h 等)も注記。グリフ・ローマ字はWikipedia「Ge'ez script」で裏取り。MD・Web版(Artifact)を作成。
2. **フィデル表 PDF化** — WebをそのままPDF化すると表の後半列が用紙外に切れる不具合が判明。印刷専用レイアウト(A4横向き、sticky解除、table-layout調整)を作り直し、Chromeヘッドレス印刷で全3ページのPDFを生成。
3. **学習内容の記録** — ここまでの内容をメモリー(次回セッション用)とMDファイルに保存。
4. **学習ロードマップ 作成** — レベル・目的(完全初心者/旅行・趣味)をユーザーに確認のうえ、7ステップ(発音→フィデル→サバイバル語彙→基礎文法→短文→リスニング→実践)の学習手順を作成。サバイバル語彙(挨拶15+数字10)、推奨リソース、12週間スケジュール例を含む。文法・語彙はWikipedia「Amharic」・Wikivoyage「Amharic phrasebook」で裏取り。MD・Web版を作成。
5. **学習ロードマップ PDF化** — 横並びgridの語彙表が用紙幅で切れ、文字が縦一列に折り返される不具合が発生。印刷専用レイアウト(A4縦向き、表を縦積みに変更、改ページ制御)を作り直し、全3ページのPDFを生成。
6. **聖書 書名一覧 作成** — アムハラ語聖書(1962年版系)の66巻と、エチオピア正教会81巻正典の追加書をゲエズ文字書名・ローマ字/カタカナ読み・日本語書名(新共同訳)・備考で一覧化。66巻の綴りは wordproject.org のアムハラ語聖書目次で確認(同目次で欠けていたゼファニヤ書を補完)。Web版は検索・旧約/新約の絞り込み付き。
7. **聖書 書名一覧 PDF化** — 印刷専用レイアウト(A4縦、table-layout固定、行の改ページ分割防止、旧約/新約/追加書ごとに改ページ)を作成。Chromeが未インストールのため Microsoft Edge のヘッドレス印刷で全7ページのPDFを生成。
8. **フィデル書き順ガイド 作成**(2026-10-20) — 基本34文字(段I)の書き順を、字形の上に色分けした筆順線・書き始めの番号で図示。ゲエズ文字には公式の筆順がない(Web検索でも統一基準は見つからず)ため、字形の構造から選んだ「学習用の目安」と明記し、5つの原則(左→右、縦線は上→下、輪は左回り、貫く線は後、派生の線は最後)で統一。下図は Noto Sans Ethiopic(OFL)のアウトラインを抽出し、中心線を手で引いて重ね合わせを画像で確認。母音7段の形の変え方はフォントの字形を見て整理。生成スクリプト `tools/build_stroke_order.py` から Web版・印刷用HTML・MD を出力し、Edge で PDF 化。
9. **あいさつフレーズ集 作成**(2026-10-22) — 時間帯・調子・自己紹介・お礼・別れ・お祝いの7場面で30フレーズを収録。アムハラ語のあいさつは相手(男性・女性・目上・複数)で語尾が変わるため、該当する12フレーズは4形すべてを掲載し、Web版は相手を選ぶと全フレーズが切り替わる。会話例と文化面の注意(長いあいさつ、肩を当てる握手など)付き。Wikivoyage「Amharic phrasebook」・Wikipedia「Amharic」で裏取り。生成スクリプト `tools/build_greetings.py` から Web版・印刷用HTML・MD を出力し、Edge で PDF 化。
10. **学習ロードマップ カタカナ修正**(2026-10-22) — サバイバル語彙表のカタカナ欄に混入していたエチオピア文字・ヘブル文字を修正(ネウォት→ネウォト、エバキህ→エバキフ、アይ→アイ、アንድ→アンド)。MD は4か所、Web版は1か所(他は修正済みだった)。PDF は印刷用HTMLが残っていないため、PyMuPDF で該当の1語だけ差し替えた(差し替え前のPDFは作業用フォルダに控えたのみで、プロジェクト内には残していない)。修正後の学習ロードマップPDFと、あいさつフレーズ集PDFを開いて表示を確認してもらった。
11. **フィデル全書き順 作成**(2026-10-26) — 基本34文字の書き順ガイドを、フィデル表の全258文字(段II〜VIIの204字と唇音化20字を追加)に広げた別資料。段II〜VIIは「基本形+印」で、基本形と同じ画は「ሀ と同じ」とまとめて表示。Noto Sans Ethiopic では ሂ・ሚ・ዒ・ፂ など手書きと形が大きく違う段があるため、フォントの形どおりに筆順を付けた。全224文字の字形を Noto Sans Ethiopic から抽出し、細線化(スケルトン)で中心線の座標を求めてから筆順線を引き、字形との重なりを画像で全文字確認。読み・画数・図の範囲・カタカナ欄の文字混入を機械チェック。生成スクリプト `tools/build_stroke_order_all.py`(筆順データは `tools/fidel_forms_all.py`、字形は `tools/glyph_outlines_all.json`)から Web版・印刷用HTML・MD を出力し、Edge で PDF 化(A4横・1ページ2系列)。
12. **GitHub に登録**(2026-10-27) — ブラウザで GitHub に `amharic-language-study` リポジトリを作成し、手元のリポジトリの送信先(origin)に登録して `master` ブランチを push した。URL: https://github.com/Yuichi-Chinen/amharic-language-study
13. **数字と買い物フレーズ集 作成**(2026-10-27) — ロードマップのゴール「あいさつ・買い物・道案内」のうち買い物にあたる資料。0〜10、11〜19 と十の位、百・千・百万、組み立ての例、ゲエズ数字(20字と例)、ブルとサンティム、値段を聞く・交渉する・買う17フレーズ(頼みごとの5フレーズは相手別の4形)、品物の単語20語、市場での会話例を収録。Web版は数を入れるとアムハラ語の読み・カタカナ・ゲエズ数字を表示する変換つき。数字・お金は Wikivoyage「Amharic phrasebook」、単語の綴りと意味は Wiktionary で裏取り。ርካሽ(安い)・ሚሊዮን(百万)と命令形(ስጠኝ・አሳየኝ・ቆይ)は辞書で直接確認できず、一般的な形と活用の規則から作成(出典欄にも明記)。「袋」(ፌስታል)は裏取りできなかったため載せていない。生成スクリプト `tools/build_shopping.py`(見た目と相手別4形の仕組みは `build_greetings.py` を読み込んで共用)から Web版・印刷用HTML・MD を出力し、Edge で PDF 化。カタカナ欄の文字混入は機械チェックで0件。

## 得られた知見

- **PDF化の注意点**: ArtifactのHTMLをそのままヘッドレスChrome印刷すると、横スクロール表・sticky要素・横並びgridが正しく印刷されない(用紙外で切れる、文字が縦折り返しになる等)。印刷用には必ず `-print.html` 版(sticky解除、table-layout固定、grid→縦積み、`break-inside: avoid`、`@page` 指定)を別途用意してから印刷する。
- **デザイン方針**: 全成果物で写本(manuscript)調のビジュアル ID を統一(朱色アクセント #AC3527系、暖色系の紙面、Noto Serif Ethiopic + Noto Sans JP)。今後新しい資料を追加する場合もこのトーンを踏襲する。
- **相手で変わる形**: アムハラ語のあいさつ・依頼は話しかける相手(男性・女性・目上・複数)で語尾が変わる。資料に載せるときは4形をそろえて示す(あいさつフレーズ集の形式)。
- **カタカナ欄の文字混入**: 生成した表でカタカナにエチオピア文字・ヘブル文字が混ざることがあった(ロードマップで4か所)。新しい資料を作ったら、カタカナ欄に U+1200〜139F・U+0590〜05FF が含まれていないか機械的に確認する。
- **印刷用HTMLの保管**: ロードマップは `-print.html` が残っておらず、PDFを作り直せなかった。今後は生成スクリプト(`tools/`)と `-print.html` を必ず残す。
